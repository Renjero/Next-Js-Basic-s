## 📖 Cheat Sheet

### Day 1 – Routing

| Concept | Syntax | Meaning |
|---|---|---|
| Basic Routing | `app/about/page.jsx` | Creates `/about` route |
| Dynamic Routing | `[slug]` | Dynamic URL segment |
| Route Parameters | `{ params }` | Access route parameters |
| Route Grouping | `(auth)` | Organizes routes without changing URL |

### Quick Syntax Revision

**1. Basic Routing**
```text
app/
 └── about/
      └── page.jsx
```

**2. Dynamic Routing**
```text
app/
 └── blog/
      └── [slug]/
           └── page.jsx
```

**3. Route Grouping**
```text
app/
 └── (auth)/
      ├── login/
      │    └── page.jsx
      └── register/
           └── page.jsx
```
